# Свечи, остатки и ароматы

## Работа в мастерской

1. В разделе **Формы** укажите название и загрузите силуэт: PNG или WebP на прозрачном фоне, до 10 МБ. Форма и силуэт — одна сущность, отдельного списка стандартных силуэтов нет.
2. В **Цветах** добавьте названия и оттенки. В **Ароматах** — названия, общие описания и ноты. Эти справочники независимы.
3. В **Остатках** нажмите **Добавить свечу**. Выберите форму, цвет и аромат из трёх выпадающих списков, введите описание, цену и количество, выберите фото и включите публикацию.
Загруженная фотография свечи имеет приоритет. Без фото используется силуэт выбранной формы, окрашенный в цвет свечи — в галерее, карточке, корзине и мастерской. Кнопка **Убрать фото — использовать силуэт** возвращает этот режим.

Для изменения карточки нажмите **Изменить свечу**. Для быстрого изменения количества нажмите на остаток. Укажите фактический доступный остаток, без уже оформленных заказов.

В таблице есть поиск и фильтры по форме, цвету, аромату и наличию. Сводка показывает суммарное количество, заканчивающиеся позиции (1–3 шт.) и позиции с нулевым остатком. При новом заказе количество уменьшается автоматически. Если остаток изменился, пока карточка была открыта, сохранение попросит обновить данные.

Используемые справочники нельзя удалить: их можно отключить. Связанные свечи исчезнут с витрины, но сохранят остаток в мастерской. При незавершённых заказах менять сочетание формы, цвета и аромата нельзя; завершите или отмените заказ либо создайте новую свечу.

## 02 / Искусство аромата

В разделе **Искусство аромата** выберите аромат. Для каждой главы **01 Начало**, **02 Сердце**, **03 Шлейф** отдельно заполните ноты и описание. Сохраните разбор. На сайте появятся введённые тексты; автоматического распределения общих нот по главам нет. Пока глава пуста, отображается сообщение о подготовке описания.

Аромат выбирается независимо от товаров, формы и цвета. Фотография блока остаётся прежней: `/assets/hero.png`. Общие название и описание аромата редактируются в справочнике **Ароматы**.

## Переход с прежней версии

Миграция `individual-candles-v1` выполняется автоматически в одной транзакции:

- создаёт справочник форм из существующих карточек;
- превращает каждое прежнее сочетание цвета и аромата в отдельную свечу с тем же количеством и фотографией;
- архивирует старые группирующие карточки, чтобы их остаток не учитывался дважды;
- сохраняет связь со старыми вариантами для возврата остатка при отмене заказа;
- сохраняет историю заказов и их снимки без перезаписи.

Позиции с прежним общим остатком сохраняют его без распределения. В мастерской они отмечены как требующие выбора цвета и аромата. До редактирования такие позиции сохраняют прежний режим выбора сочетания на витрине. После выбора трёх значений остаток относится к конкретной свече. Неподтверждённые корзины со старыми вариантами могут потребовать повторного выбора товара; повтор уже отправленного запроса не создаёт второй заказ.

Удаление незавершённого заказа возвращает зарезервированные свечи. Выполненные и старые не резервировавшие остаток заказы количество не меняют. Если у старого заказа был общий остаток, который ранее вручную разделили по вариантам, требуется ручная сверка.

## Проверка

```sh
npm ci
TEST_DATABASE_URL=postgresql://... npm run test:catalog
npm run test:ui
npm run lint
npm run build:amvera
TEST_DATABASE_URL=postgresql://... npm run test:http
```

Серверные тесты работают в собственных временных схемах тестовой PostgreSQL. GitHub Actions выполняет их на PostgreSQL 17.5. DOM-тесты проверяют выпадающие списки, справочники, остатки, фильтры, корзину и главы аромата; это функциональная проверка, без визуальной проверки CSS.

## Загружаемые силуэты

У формы редактируются название и файл силуэта. Можно заменить или убрать изображение. Без фото и без силуэта показывается нейтральная заглушка. Прежние встроенные силуэты сохраняются у старых форм до замены; новые формы используют свои файлы.

Автоматическое обновление добавляет поле `candle_forms.silhouette`, допускает отсутствие старого поля `shape`. Остатки, цены и ароматы не меняются. Файлы хранятся в прежнем `/data/uploads`; заменённые файлы сохраняются для истории заказов.

## Формы в «Побыть мастером»

Включённые формы из справочника автоматически доступны в конструкторе, в том числе формы, для которых ещё нет готовых свечей в каталоге. Варианты показывают свои названия и силуэты; выбранный силуэт на рабочем столе окрашивается в выбранный цвет. Добавлять форму отдельно в конструктор не нужно. Отключённые или удалённые формы нельзя выбрать для нового заказа.

В корзину передаётся отдельный рецепт с `formId`. Сервер проверяет доступность формы и сохраняет её название и изображение на момент заказа. Редактирование справочника не меняет историю заказов. Индивидуальный заказ остаётся «По запросу» и не списывает готовые свечи со склада. Старые рецепты с прежними встроенными формами и повторные отправки ранее созданных заявок продолжают обрабатываться.

Новые таблицы и переменные окружения для этого изменения не нужны.
