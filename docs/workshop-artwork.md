# Workshop stone pedestal

Asset: `public/assets/workshop-stone.webp` (1100 × 733, WebP with alpha).

Created with the built-in imagegen tool on 2026-09-26. The generated transparent photograph was resized and encoded as WebP for the website. It is a separate stone layer beneath the live candle silhouette, not a flattened photograph of a fixed candle. Aroma backgrounds continue to use the photographs selected in the existing aroma editor.

## Final generation prompt

Use case: product-mockup. Asset type: transparent photographic stone pedestal layer for a luxury candle configurator. Generate one isolated low, wide, rugged charcoal-black basalt rock plinth with a mostly flat horizontal top, photographed almost straight-on, camera slightly above the top surface, like a premium niche fragrance still life. The entire rock is visible, no cropping. The top plane is centered at about 32% of the object's height, broad and flat enough for a candle to be composited exactly at the center. Rough layered slate edges, fine authentic mineral texture, tiny warm ivory highlights from soft light above left, rich deep shadows below. Object occupies 90% of canvas width and 70% of height, landscape 3:2 canvas, transparent empty margins. Moody dark natural stone, quiet editorial luxury, photorealistic, beautifully detailed but minimal. Actual transparent background with alpha, no floor, no environment, no gradient background. NO candle, NO flame, NO smoke, NO text, NO logo, NO additional objects. This empty pedestal will be composited underneath a separately rendered interactive candle on changing dark aroma photographs.
