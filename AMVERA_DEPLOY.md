# Развёртывание ТИХО в Amvera

Для обновления существующего магазина с ароматами и вариантами см. [AROMAS_UPDATE.md](AROMAS_UPDATE.md).

Проект подготовлен как единое Next.js-приложение в Docker: магазин, защищённая админка и API работают на одном домене.

## Что где хранится

- товары, цены, остатки и адреса фотографий — в PostgreSQL;
- файлы JPG, PNG и WebP — на постоянном диске Amvera в `/data/uploads`;
- пароль администратора и ключ сессии — только в секретах Amvera;
- исходный код — в GitHub, без фотографий, базы и секретов.

## Настройка

1. Создайте пустой приватный репозиторий GitHub и загрузите туда проект.
2. В Amvera создайте приложение из GitHub-репозитория в режиме Docker. Используется корневой `Dockerfile`, порт контейнера — `3000`.
3. Создайте PostgreSQL и скопируйте строку подключения в секрет `DATABASE_URL`.
4. Подключите постоянное хранилище к каталогу `/data`.
5. Добавьте переменные:
   - `UPLOAD_DIR=/data/uploads`
   - `ADMIN_PASSWORD` — длинный пароль входа;
   - `SESSION_SECRET` — случайная строка не короче 32 символов;
   - `PGSSL=true`, если это требуется параметрами базы.
6. Запустите сборку. Таблица товаров и начальные позиции создадутся автоматически при первом запросе.
7. Откройте `/admin`, войдите с `ADMIN_PASSWORD` и загрузите фотографии.

## Резервное копирование

Нужно включить резервные копии PostgreSQL. Каталог `/data/uploads` также следует периодически архивировать или синхронизировать с объектным хранилищем.
